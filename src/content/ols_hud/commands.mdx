## Ranges for `/ids` and `/ooc`

- **`idsCommand.radius`** — how far the `/ids` command looks for other players (meters).
- **`oocCommand.radius`** — intended OOC range in config. **Current behavior:** the server script uses the **same radius as `idsCommand`** when gathering nearby players for OOC. See [Main config](/ols_hud/configs/main#local-ooc-ooccommand).

## Disabling commands

Set `enabled = false` inside the matching block in `configs/main.lua` for announce, team chat, IDs, or OOC. Restart **`ols_hud`** after saving.

## Locale text

Titles and bodies for announce, team chat, IDs, and OOC use **`locales/*.json`**. Edit those files to change wording — see [Locales & data files](/ols_hud/configs/locales-and-data).
